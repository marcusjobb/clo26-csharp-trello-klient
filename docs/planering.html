Projektplanering med beskrivningar

Få en plan där varje task har mål, kodexempel, förklaringar och "klart när". AI:n visar först bara kortnamnen, så att du kan godkänna upplägget.

Ska AI:n skapa korten åt dig? Läs det här först
  • AI-agent på din dator (Claude Code, Copilot agent …): Trello kräver API-nyckel + token. Token är den blå länken "Token" på Trellos API-key-sida, inte "Secret". Lägg dem i en gitignorerad secrets.json. För GitHub: kör gh auth login.
  • Webb-AI (claude.ai, ChatGPT …): koppla Trello eller GitHub under inställningarna (Connectors / Integrationer / Appar).
  • Ingen koppling? Välj "bara text" nedan och klistra in korten själv.
  • Klistra aldrig in nycklar i chatten. Har det hänt: generera nya.
