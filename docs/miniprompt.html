Miniprompt: dela upp ett projekt

Beskriv projektet med tre rader. Du får en prompt som ber AI:n om uppgifter i ordning med tidsåtgång.

Din prompt

Granska förslaget innan du använder det

Gå igenom AI:ns tabell rad för rad:

  • Kan jag förklara uppgiften med egna ord? Om inte: ta bort den, eller fråga läraren vad den betyder.
  • Är den för stor? Tar den längre tid än gränsen, eller innehåller den flera "och": skriv om den till flera mindre uppgifter.
  • Är ordningen rimlig? Kan jag göra uppgift 5 utan att 1–4 är klara?
  • Leder den mot "klart när"? Uppgifter som inte hjälper till dit kan vänta.

Det är din lista när du är klar, inte AI:ns.
